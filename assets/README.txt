This folder is where downloadable files live — most importantly your resume.

To make the "Download Resume" button in the hero section work:
1. Export your resume as a PDF.
2. Name it exactly: Rabia_Arain_Resume.pdf
3. Drop it into this /assets folder.

The button in index.html already points to "assets/Rabia_Arain_Resume.pdf",
so no code changes are needed once the file is here.
